# Переклад гри

Мови: українська (основна, вихідна) та англійська. Мову обирають у «Налаштування → МОВА / LANGUAGE» (у меню й у бою). При першому запуску мова відповідає мові системи: uk / ru / be — українська, інакше — англійська. Для тестів є аргумент `-- --lang=en`.

## Як це влаштовано

- Ключ перекладу — **сам український текст**. У коді: `Loc.t("Текст")`. Підстановки додаються після перекладу: `Loc.t("Втрати: %d") % n`.
- Переклади лежать у `locale/en.po` (стандартний gettext). Godot підхоплює його через налаштування проєкту `internationalization/locale/translations`. Файл відкривається в Poedit або будь-якому текстовому редакторі.
- Таблиці з текстом (`Game.CATALOG`, `MISSIONS`, `CAMPAIGN_STEPS`, `DIFFICULTY`, `WEATHER`, `KEY_ACTIONS`, `Db.VEHICLES / ROLES / WEAPONS`, назви рангів, рівнів стресу тощо) — це змінні. Їхні українські оригінали лежать у константах `*_UK`, а `Loc.localize_all()` перекладає їх при зміні мови.
- Тексти карт (назва, завдання, опис, розвіддані, позначки, райони висадки, назви загонів) перекладає `Loc.localize_def()` під час завантаження карти. Оригінали зберігаються на самій карті.
- Імена бійців в англійській транслітеруються (`Loc.person`, офіційна українська транслітерація: Коваль → Koval).
- Однакові українські слова з різним значенням розрізняє контекст після `@`: `Loc.t("ПОСАДКА@десант")`. В українській частина після `@` не показується.

## Скрипт `tools/i18n.py`

```
python -X utf8 tools/i18n.py wrap        # обгорнути нові українські рядки в коді в Loc.t(...)
python -X utf8 tools/i18n.py pot         # зібрати всі рядки -> locale/strings.pot, оновити en.po,
                                         # неперекладені — у locale/todo_en.txt (з номерами)
python -X utf8 tools/i18n.py apply FILE  # FILE: рядки "номер<TAB>переклад" для todo_en.txt
python -X utf8 tools/i18n.py fix-edges   # вирівняти пробіли й переноси на краях за оригіналом
python -X utf8 tools/i18n.py stats
```

`wrap` не чіпає:
- рядки-ідентифікатори: порівняння `==` / `!=` / `in`, ключі словників, `match`, аргументи `has` / `get` / `begins_with`;
- константи й змінні рівня класу (вони рахуються до вибору мови);
- `print`;
- редактор карт і тестові скрипти.

Такий текст перекладається там, де його показують: `Loc.t(значення)`.

## Робочий процес для нового тексту

1. Пишіть текст українською, як завжди. Можна одразу `Loc.t("...")`, а можна потім запустити `wrap`.
2. `pot`, переклад нових рядків з `locale/todo_en.txt` → `apply`.
3. Перевірка: `-- --shots=<папка> --lang=en`. Кожен знімок перевіряється на кирилицю у видимому інтерфейсі, знахідки друкуються рядками `[CYR] <знімок>: <текст>`.

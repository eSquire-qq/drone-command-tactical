# Редактор карт у Godot

Карти гри — звичайні сцени Godot. Редактор показує карту такою самою, як у грі: землю з викопаними окопами, дороги, вирви, посадки з деревами, кущі, траву, паркани, дріт, «зуби дракона», будинки, сараї, мішки, ДЗОТи, техніку й РЕБ. Об'єкти беруться з готової бібліотеки.

## Як почати

1. Відкрийте проєкт у Godot. Угорі поруч із 2D / 3D / Script / AssetLib з'явиться вкладка **«Карта»** (плагін «Редактор карт»). Якщо її немає: Project → Project Settings → Plugins → «Редактор карт» → Enable, або перезапустіть Godot.
2. Відкрийте карту, двічі клацнувши файл у FileSystem (`maps/field.tscn`, `maps/treeline.tscn`, `maps/training.tscn` або свою з `maps/custom/`). Редактор сам перемкнеться на вкладку **«Карта»**.
3. **Нова карта:** кнопка **«Нова карта…»** зліва вгорі на вкладці «Карта». Введіть ім'я латиницею, і карта створиться з шаблону (посадки, дорога, окоп, загін противника, усі маркери місії) та відкриється.
4. **F6** запускає бій на відкритій карті. Карти з `maps/custom/` також з'являються в меню гри → «Окремий бій».
5. **Ctrl+S** зберігає карту.

## Камера (як у грі)

| Дія | Як |
| --- | --- |
| Рух | **WASD** або стрілки; **права кнопка + тягнути**. Shift — швидше |
| Ближче / далі | **колесо миші** |
| Поворот | **Q / E** |
| Нахил і поворот мишею | **середня кнопка + тягнути** |
| Вся карта | **H** або кнопка «Вся карта» |
| До вибраного об'єкта | **F** |

Клавіші працюють, коли миша над картою (клацніть по ній один раз).

## Додавання об'єктів

1. Ліворуч на вкладці «Карта» — палітра готових об'єктів за категоріями. **Клацніть потрібний** (кнопка підсвітиться).
2. **Клацайте по землі** на карті: кожен клік ставить ще один такий об'єкт. Жовте кільце показує, куди він стане.
3. **Права кнопка або Esc** завершує розстановку.

**Лінії** (окоп, хід сполучення, дорога, паркан, дріт, «зуби», мінне поле, балка, вал) малюються так:
1. виберіть лінію в палітрі;
2. **клацайте точки по черзі**;
3. **Enter або права кнопка** завершує лінію, **Backspace** прибирає останню точку.

Окоп одразу викопується в землі, дорога лягає на землю.

Ще один спосіб: перетягнути файл із `maps/objects/` (панель FileSystem) прямо на карту.

## Редагування

- **Клік по об'єкту** вибирає його. Праворуч, в **Inspector**, його налаштування: розмір будинку, зруйнованість, довжина мішків, густота посадки, висота пагорба, ширина дороги, тип мін, ролі бійців загону тощо. Біля кожного поля є підказка.
- **Тягніть** вибраний об'єкт мишею, щоб перемістити.
- **R** — повернути на 15° (Shift+R — назад), або **Shift+колесо**.
- **Delete** — видалити, **Ctrl+Z** — скасувати будь-яку дію.
- **Вибрана лінія** показує жовті точки:
  - тягніть точку, щоб перемістити її;
  - **Shift+клік** по землі додає точку в кінці;
  - **права кнопка** на точці видаляє її.
- **Загін противника:** виберіть загін, потім у палітрі «Позиція бійця» і клацайте по землі, щоб додати позиції саме цьому загону. Ролі бійців задаються в Inspector (`leader`, `rifleman`, `mg`, `at`, `atgm`, `grenadier`…).
- **Земля перебудовується сама** приблизно за пів секунди після зміни. Кнопка «Перебудувати землю» робить це примусово.
- **«Підписи»** вмикає й вимикає написи над об'єктами.
- Налаштування всієї карти — в Inspector кореня (виберіть верхній вузол у панелі Scene):
  - «Карта»: назва, розмір, Seed, Relief, Tilt, Environment;
  - «Місія»: завдання, фіксовані сили;
  - «Розвіддані»: тексти брифінгу.

Звичайна вкладка **3D** теж працює. Там можна правити ті самі вузли стандартними інструментами Godot.

Бібліотека (`maps/objects/`, ті самі кнопки, що й у палітрі):

| Категорія | Об'єкти |
| --- | --- |
| Рослинність | Дерево, Сухе дерево, Кущ, Великий кущ, Гай, Посадка 60 м, Ліс 40×40 |
| Рельєф | Пагорб, Западина, Балка, Вал, Вирва мала, Вирва велика, Згарище |
| Окопи й дороги | Окоп (з траверсами), Окоп прямий, Хід сполучення, Окоп з бліндажем, Бліндаж, Дорога, Польова дорога |
| Споруди й укриття | Будинок (руїна), Будинок (майже цілий), Сарай, Мішки з піском, Тюк сіна, Стовп, Підбита БМП-1, Підбитий M113, Паркан |
| Загородження | Колючий дріт, Зуби дракона, Мінне поле ПП, Мінне поле ПТ |
| Противник | Загін стрільців, Кулеметний розрахунок, Розрахунок ПТРК, Позиція бійця, ДЗОТ, Бліндаж противника, Станція РЕБ, Макет РЕБ, Маскування позиції |
| Місія | В'їзд техніки, Поява піхоти, Точка висадки, В'їзд евакуації, Точка збору, Відхід противника, Камера на старті, Центр знімка, Ціль, Зона захоплення, Пристріляна зона, Позначка розвідки, Район висадки (вибір на брифінгу), Зона вільного вибору висадки |

## Що бачить гра

Гра будує карту з тих самих вузлів тим самим кодом (`MapManager`), тож у бою все стоїть рівно там, де в редакторі. Руїни, дерева й кущі мають ту саму форму, бо їхні випадкові деталі залежать лише від Seed карти й позиції об'єкта.

Умовні кольорові позначки підказують, що є чим:
- рамки — зони місії;
- кольорові стовпчики — маркери й позиції противника (червоні — основні, помаранчеві — запасні, фіолетові — відхід);
- блідий прямокутник — межа посадки.

## Обов'язковий мінімум для бою

Ось що має бути на карті (у шаблоні вже є):
- В'їзд техніки — синя вісь −Z показує напрям;
- Поява піхоти;
- хоча б одна Точка висадки;
- В'їзд евакуації;
- Точка збору;
- Відхід противника;
- Ціль;
- Зона захоплення;
- хоча б один загін противника з позиціями.

Необов'язково — **вибір району висадки на брифінгу**. Маркер «Район висадки» має назву (поле «Підпис») і пояснення. Таких маркерів може бути кілька. «Зона вільного вибору висадки» — прямокутник, де гравець може клацнути будь-яку точку. Якщо є хоча б одне з двох, на знімку брифінгу й планування з'являються сині точки, а клік вибирає, куди йде колона. Точки висадки зберігають своє розташування навколо обраного району. Щоб знімок їх показав, «Центр знімка» і розмір знімка мають охоплювати ці райони.

## Де що лежить

| Шлях | Що це |
| --- | --- |
| `maps/*.tscn`, `maps/*_heights.res` | офіційні карти («Посадка», «Висота», «Хутір», «Лісовий масив», «Квартал», «Полігон») та їхній запечений рельєф |
| `maps/custom/` | ваші карти (автоматично в меню) |
| `maps/objects/` | бібліотека готових об'єктів (генерується: `-- --make-library`) |
| `maps/templates/Нова карта.tscn` | шаблон нової карти |
| `addons/map_editor/` | вкладка «Карта» (камера, палітра, редагування мишею) |
| `scripts/map/editor/` | вузли карти (`MapScene`, `Map…`), конвертер, бібліотека |
| `scripts/map/map_models.gd` | моделі споруд, спільні для редактора й гри |
| `backup/` | резервні копії карт і коду від 26.11.2026 |

## Корисні команди

```powershell
& "E:\Steam\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe" --path . -- --preview-map=res://maps/custom/моя_карта.tscn
```

Ця команда зберігає знімки вигляду карти з редактора в `user://`.

```powershell
& "E:\Steam\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe" --headless --fixed-fps 60 --path . -- --autotest --map=res://maps/custom/моя_карта.tscn
```

Тут бот сам грає вашу карту й штурмує ціль.

## Бій у будівлях

- Будинки мають **вікна, двері** й (після вибухів) **проломи**. Біля вікна боєць стріляє назовні й має добре укриття; углибині його не видно.
- **Противник у будинку:** поставте «Позицію бійця» загону всередині будинку — у бою він займе найближче вікно.
- **Наші:** у режимі «Рух» чи «Тримати» ПКМ по будинку — зайняти будівлю; у режимі «Штурм» чи «Зачистка» ПКМ по будинку — зачистити (граната всередину, вхід через двері чи пролом).

## Руйнування (на будь-якій карті)

- Вирви від мін, мін на полі й 73-мм снарядів справді продавлюють землю.
- Дерева падають від вибухів.
- Стіни будинків і сараїв руйнуються метр за метром, і крізь пролом проходить піхота.
- Мішки, тюки, бліндажі й ДЗОТи пошкоджуються та руйнуються.

## Ліс

Посадка (MapTreeline) має два додаткові параметри:
- **Kind** — порода дерев: листяні (посадка), сосни або мішаний ліс;
- **Sight Block** — наскільки дерева закривають огляд. 0 означає «як густота»; для соснового лісу підходить ~0.2 (огляд 20–35 м).

Техніка через ліс не проїжджає: для неї потрібні дороги (MapRoad). Широка дорога (6–7 м) у лісі — це просіка.

Тексти карти (назва, завдання, розвіддані) пишіть українською. Англійський переклад додається через `tools/i18n.py`, див. `docs/LOCALIZATION.md`.
